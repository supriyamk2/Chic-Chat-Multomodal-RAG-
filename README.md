# 👗 Chic-Chat: Multimodal RAG for Fashion Recommendations

**Chic-Chat** is a multimodal Retrieval-Augmented Generation (RAG) application that combines visual and textual understanding to offer fashion recommendations. It uses **CLIP** for multimodal embeddings and integrates with **ChromaDB** for image and text retrieval, topped with a conversational layer powered by LLMs.

> 🔗 [Live Repo](https://github.com/supriyamk2/Chic-Chat-Multomodal-RAG-/tree/main)

---

## 🧠 Overview

This project demonstrates how to build an AI system that:
- Accepts image and/or text input from users.
- Retrieves similar items or styles based on embeddings.
- Uses generative models like GPT to provide styling suggestions and recommendations.

It is particularly useful in domains like **fashion**, where user preferences span **both visual and descriptive attributes**.

---

## ✨ Features

- 🔍 **Image-to-Image Search**: Upload an outfit image and retrieve visually similar styles.
- 📝 **Text-to-Image Search**: Input a phrase like *"casual outfit with jeans"* and get matching images.
- 🤖 **Multimodal Fusion**: Combines image and text features to understand user intent deeply.
- 💬 **Conversational Output**: Generates natural language responses using GPT-style LLMs.
- 🧠 **Zero-Shot Reasoning**: Thanks to CLIP, no task-specific training is needed for retrieval.
